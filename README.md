# Toolbox

Toolbox is a small website with useful everyday tools in one place.

## Tools

The project includes:

1. Focus timer

1. Tasks

1. Notes

1. Password generator

1. Unit converter

1. Customs duty estimate

1. Color picker

1. Calculator

1. Random picker

1. Habit tracker

## Features

The site includes light mode, dark mode, local browser storage, keyboard controls, breadcrumbs, direct tool links, loading animations, and an interactive 3D background.

Tasks, notes, habits, and theme settings are saved in the current browser. No account is required.

## Run locally

Start a local server from the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```
http://localhost:8000
```

## Main files

```
index.html   page structure
style.css    layout and styling
script.js    tools and interactions
404.html     custom error page
```

## Notes

The project is currently a static frontend. Data does not sync between devices yet.

The customs tool gives a rough estimate only and should not be treated as official tax or customs advice.
